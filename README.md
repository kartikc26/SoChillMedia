# SoChillMedia Website — Documentation

## 📁 Size Explained

| What | Size | Goes to GitHub? | Goes to Vercel? |
|------|------|----------------|-----------------|
| `node_modules/` | ~300 MB | ❌ NO | ❌ NO |
| `.next/` (build cache) | ~29 MB | ❌ NO | ❌ NO |
| **Your actual code** | **~500 KB** | ✅ YES | ✅ YES |

**Why is the folder 329 MB locally?**
- `node_modules/` contains all downloaded packages (React, Next.js, GSAP, Tailwind, etc.). This is generated by `npm install` and is **never pushed to GitHub**.
- `.next/` is a local dev/build cache. Also **never pushed**.
- The `.gitignore` file already excludes both.

**What actually gets pushed to GitHub: ~500 KB (20 files)**
- Your source code, config, and the logo image.
- That's it.

**What happens on Vercel:**
1. Vercel reads your ~500 KB source from GitHub
2. Vercel runs `npm install` on their own servers (their storage, not yours)
3. Vercel builds and deploys
4. You use virtually **zero** of your free Vercel/GitHub storage

## 🚀 How to Deploy

```bash
# 1. Initialize git (one-time)
git init
git add .
git commit -m "Initial commit"

# 2. Push to GitHub
git remote add origin https://github.com/YOUR_USERNAME/sochillmedia.git
git push -u origin main

# 3. On Vercel
# - Import the GitHub repo
# - Framework: Next.js (auto-detected)
# - Click Deploy
# - Done. It will auto-deploy on every push.
```

## ✏️ How to Edit Content

**ALL website text/data lives in ONE file:**

### `src/data/site-data.ts`

---

### Change Contact Info

```ts
export const contactInfo = {
  phone: "+917249992499",          // ← change phone
  email: "aryankapoor@sochillmedia.in",  // ← change email
  instagram: "https://www.instagram.com/sochillmedia.co",
  instagramHandle: "@sochillmedia.co",
  website: "sochillmedia.in",
  whatsapp: "https://wa.me/917249992499",  // ← change WhatsApp
};
```

---

### Add/Remove Team Members

```ts
export const team = [
  {
    name: "Aryan Kapoor",               // ← full name
    role: "Founder & Creative Director", // ← their role
    vibe: "The one who started it all",  // ← short tagline
  },
  // ADD NEW MEMBER: just copy-paste this block ↓
  {
    name: "New Person",
    role: "Their Role",
    vibe: "Short catchy line about them",
  },
];
```

To **remove** someone: delete their `{ name, role, vibe }` block.

---

### Add/Remove Services

```ts
export const services = [
  {
    title: "Social Media Management",    // ← service name
    description: "Instagram, Facebook...", // ← short description
  },
  // ADD NEW SERVICE: copy-paste ↓
  {
    title: "New Service Name",
    description: "What this service includes.",
  },
];
```

---

### Update Stats (numbers)

```ts
export const stats = [
  { value: "500+", label: "Reels Created" },
  { value: "50+", label: "Brands Served" },
  { value: "100%", label: "Client Retention" },
];
```

Just change the `value` and `label` strings.

---

### Change Nav Links / Scroll Positions

```ts
// Percentages (0 to 1) — works on any device/screen size
export const navScrollProgress: Record<string, number> = {
  services: 0.35,  // 35% down the page
  team: 0.58,      // 58% down the page
  contact: 0.82,   // 82% down the page
};

export const navLinks = [
  { label: "Services", key: "services" },  // ← what shows in navbar
  { label: "Team", key: "team" },
];
```

To add a nav button: add to both `navScrollProgress` and `navLinks`. See `DOCS.md` for full guide.

## 🎨 How to Change Colors

Edit `src/app/globals.css`:

```css
:root {
  --background: #0a0a0a;    /* ← page background (dark) */
  --foreground: #f5f5f5;    /* ← text color (light) */
  --accent: #0033CC;        /* ← brand accent (blue) */
}
```

And in `tailwind.config.ts`:
```ts
accent: "#0033CC",       // ← button/accent color
"accent-dark": "#002299", // ← hover state
```
